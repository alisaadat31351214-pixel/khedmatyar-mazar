# تست خودکار

`python tests/smoke.py` — ۱۶ بررسی روی سایت و پنل (سفارش، کد پایان کار، پنل همکار، دکان، قرآن، تقویم، پنل مدیر، تعطیلی سفارش، حالت صرفه‌جویی). پاسخ‌های Supabase شبیه‌سازی می‌شوند، پس **ثابت نمی‌کند دیتابیس واقعی درست کار می‌کند**؛ برای آن `docs/TEST_PLAN.md` را دستی انجام دهید.

نیازمندی: `pip install playwright` و `playwright install chromium`.
